# 🕒 Clock Web Application

This is a simple Clock web application built using **HTML**, **CSS**, and **JavaScript**. It displays the current time and updates every second.

## 💻 Features

- Live updating digital clock  
- Styled with CSS for a clean, minimal look  
- Vanilla JavaScript – no external libraries  
- Responsive design (optional if implemented)

## 🧰 Technologies Used

- HTML5  
- CSS3  
- JavaScript
